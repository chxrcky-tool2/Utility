# ChxrCky 
---
## 🚀 Features
---
### ⚙️ Core Engine
*   **Standalone Architecture**: Built independently from the ground up with zero external dependencies or third-party wrappers.
*   **High-Fidelity Sequence Capture**: Supports high-frequency input recording while strictly preserving native physics calculations.
*   **Advanced Data Compression**: Utilizes a bit-packed binary (`.cky`) serialization format to maintain minimal file sizes, even for massive datasets.
---------------------------------------
### PlayBack & Automation
*   **Synchronous Dual-Input Processing**: Accurately captures and reproduces simultaneous primary and secondary input streams.
*   **Stateful Checkpoint Restoration**: Intelligent state tracking allows for seamless sequence recovery from previous checkpoints without breaking playback integrity.
*   **High-Frequency Input Emulator**: Built-in rapid-input generation utilizing frame-window accumulation to prevent engine overload.
*   **Time-Dilation Controls**: Freeze the simulation and advance time frame-by-frame, with support for micro-inputs while the engine is paused.
-----------------------------
### Utility & Interface
*   **Dynamic Audio Profiles**: Supports custom external audio files and modular folder structures for realistic auditory input feedback.
*   **Live Telemetry HUD**: Real-time on-screen display tracking active inputs, performance, and cumulative actions.
*   **Extended Temporal Scaling**: Full spectrum control from being slow, to being little fast, to hyper-fast!
*   **Coordinate Manager**: Toggle-Able position-switching utility.
*   **Integrated Integrity Protection**: Automatically blocks native progress saving if any utility module is active.
*   **Custom Interface**: Tidy, scrollable UI with multiple themes and an integrated built-in license viewer.
