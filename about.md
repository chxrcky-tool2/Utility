# ChxrCky Macro Bot

### Features
- ImGui and Cocos User Interface
- Multiple UI Themes (Mono, Forest, Neon, Sunset, Ocean)
- Customizable, draggable Cky Icon
- Show Trajectory with adjustable length
- Frame Stepper with backstep functionality
- Frame Fix velocity and interval settings
- CKY1, CKY2, CKY3, and CKY4 Macro Formats
- Import GDR files
- Custom TPS Slider (1 to 6000)
- Input Offset Slider
- Click Packs with adjustable volume
- Checkpoint Telemetry
- HUD Displayer Settings
- Noclip
- Speedhack with manual text input
- 20 Macro Save Slots
