# ChxrCky Macro Bot
---
ChxrCky is a macro bot that has a beautiful interface and cool features. It can help with botting, practicing via noclip, and more! It consists of features designed to distinguish such features. Enjoy playing, and Enjoy worthwhile features!
---
### Features
- ImGui and Cocos User Interface
- Multiple UI Themes ( Neon, Ocean, and more )
- Customizable, draggable Cky Icon
- Show Trajectory with adjustable length
- Frame Stepper with backstep functionality
- Frame Fix velocity and interval settings
- Built in Full sub-frame physics snapshot
- Import GDR files
- Custom TPS Slider (1 to 6000)
- Input Offset Slider
- Click Packs with adjustable volume
- Checkpoint Telemetry
- HUD Displayer Settings
- Noclip
- Speedhack with manual text input
- 20 Macro Save Slots
- Replay engine
