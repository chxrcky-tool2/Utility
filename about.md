# ChxrCky Utility

ChxrCky is a comprehensive, client-side utility and kinematic sequence emulator designed for Geometry Dash. Built specifically for precision gameplay analysis and engine testing, it provides a stable environment to record, analyze, and manipulate localized gameplay states directly on your Android device.

### Core Features

*   **Input Sequence Recorder and Re-enactment:** Log and accurately re-inject input events at the exact physics tick for 1:1 automated state recreation.
*   **Temporal Step Decoupling:** Override default tick rates for micro-precision testing and frame-perfect analysis.
*   **Time-Scale Modifier and Audio Sync:** Adjust execution velocity while maintaining auditory pitch alignment.
*   **Render Loop Rate Decoupling:** Unlock native hardware frame rates for visual smoothness.
*   **Progress Integrity Guard:** Prevent illegitimate stat progression while active modifications are engaged.
*   **Discrete Physics Frame Advancer:** Step through the simulation tick-by-tick for collision analysis.
*   **Checkpoint State Allocator:** Capture, store, and transition between multiple predefined physics states.
*   **Multi-Slot Storage Framework:** Manage and archive distinct input sequences without overwriting existing data.

### Usage

Once the utility is placed in your Geode mods directory, it can be accessed via the custom Cky button located on the main menu. The interface features a draggable design with dedicated tabs for Bot, Global, Player, Display, and Settings.

### Disclaimer

This software is a client-side utility developed for educational purposes and local engine analysis. It is intended for personal use and does not interact with online leaderboards or inject malicious code. Use responsibly.
